C1–C3 · conceitos

Compartilhar com segurança

C1

Samba e SMB

O SMB é o protocolo de compartilhamento de arquivos do Windows. O Samba faz o Linux falar SMB: o servidor Linux vira pasta de rede no Explorador do Windows.

1[financeiro]2   path = /srv/financeiro3   valid users = @financeiro4   read only = no5   create mask = 06606   directory mask = 0770
C2

Identidade híbrida

Empresas com Active Directory local costumam sincronizar as contas com o Microsoft Entra ID: o mesmo usuário e senha no computador da empresa e no Microsoft 365.

C3

Issues como chamados de suporte, Wiki como base de conhecimento e Projects para acompanhar as tarefas. Inventário, topologia, usuários e políticas documentados no repositório.

EC1 · estudo de caso

O verme que andava pelo compartilhamento

Em 12 de maio de 2017, o WannaCry criptografou cerca de 200 mil computadores Windows em mais de 150 países, entre eles os do sistema público de saúde britânico. Ele se espalhava sozinho por uma falha na versão antiga do SMB (SMBv1), na porta 445.

A correção da Microsoft tinha saído dois meses antes. Muitos computadores não tinham sido atualizados.

Para discutir em grupo

  1. Por que um protocolo de compartilhamento virou caminho de ataque?
  2. Que configuração do Samba e do Windows evita o SMBv1?
  3. Como o projeto do grupo vai cuidar das atualizações?

Fonte: Cloudflare, sobre o ataque WannaCry.
