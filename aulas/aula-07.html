C1–C3 · conceitos

Quem pode o quê

C1

Permissões rwx

Cada arquivo tem permissões de leitura (r), escrita (w) e execução (x) para o dono, o grupo e os outros.

Em números: r=4, w=2, x=1. 750 é tudo para o dono, ler e executar para o grupo, nada para os outros.

1sudo chown ana:financeiro relatorio.xlsx2sudo chmod 640 relatorio.xlsx3ls -l relatorio.xlsx4# -rw-r----- ana financeiro
C2

sudo e menor privilégio

Ninguém trabalha como root no dia a dia. Quem precisa de poder administrativo usa sudo, que pede senha e registra o que foi feito.

C3

Políticas de senha

Tamanho mínimo, complexidade e expiração. No Linux, chage define a validade. No Windows, as Políticas de Grupo aplicam a regra a todos de uma vez.

1sudo chage -M 90 ana   # expira em 90 dias2sudo chage -l ana
EC1 · estudo de caso

A planilha de salários aberta para todos

Na Contábil Exata (fictícia), a planilha de salários ficou numa pasta compartilhada com permissão 777, "porque estava dando erro de acesso". Um estagiário abriu sem querer e o assunto virou o almoço da semana.

Para discutir em grupo

  1. O que significa 777?
  2. Que permissão a planilha deveria ter? Para qual grupo?
  3. Por que "dar 777 para resolver" é a pior solução para erro de acesso?

Caso fictício, criado para a aula.

M

Matemática

rwx é binário: 111 = 7, 110 = 6, 100 = 4. As permissões do Linux são três números em base 8.

Chave geral, disjuntor e tomada: cada nível da instalação elétrica tem um acesso diferente. Permissões são a mesma ideia.
